Works with SG LEDDim Smart. The first generation (@NDxxxx in Bluetooth) is stable. Later generations and LEDDim Smart Pill are being tested. Let us know how it goes in the forum thread.

Homey Pro controls the dimmers directly over Bluetooth, without a gateway. Add one device for each dimmer. First-generation dimmers can also be grouped. You can turn the lights on and off and adjust brightness. With the first generation, you can also keep the dimmers connected for faster control. Changes made at the wall switch then show up right away.

Commands are encrypted using the network password, which is usually 1234. If you get a wrong password warning, check Network Isolation in the SG app. Turn it off to use 1234, or enter your home's password in the settings for each dimmer. If you turn it off, all devices must be set up again in the SG app.

Requires Homey Pro. Does not work with Homey Bridge or SG Smart 3.0. SG Smart 3.0 can connect to Homey through SG Smart Gateway 3.0 and Matter. This app is unofficial and not made or supported by SG. Based on CSRmesh work by nkaminski, fromm1990, einaros and erlwes. Open source.
